# 第三轮实验协议 v1：预测风险奖励的单机制消融

日期：2026-09-09。P3-03 已完成：本文件确定实验设计；**算法尚未实现，训练未启动，最终场景未生成**。参数在 P3-04 实现及 P3-05 运行中不得根据最终测试修改。机器可读约定见 [experiment_protocol.json](../configs/round3/experiment_protocol.json)。

## 1. 选择与假设

选定机制：在原奖励上增加一个有界、线性的“短时预测风险惩罚”。不扩展 16 维输入，不改网络，不接管动作，不同时改变原静态/动态奖励权重。

依据是开发诊断观察到速度均值饱和、失败回合缺少减速，以及静态惩罚区进入到碰撞的中位时间仅 0.8 s。这提示反馈可能偏晚，但不能证明预测奖励一定有效。

主假设：相比同尺度的额外即时风险惩罚，预测风险惩罚能够提高共同常规测试上的成功率。辅助假设：在预测风险较高的状态，策略更愿意减速或提前转向，且不会以大量停车超时换取低碰撞率。

本轮不选择风险观测扩维或安全层：前者同时改变输入表达，后者可能只靠动作接管改善安全，均不利于先隔离奖励反馈时机的作用。它们保留为未来备选，不判定为无效方案。

## 2. 对照组与预算

| 组名 | 奖励 | 作用 | 训练 |
|---|---|---|---|
| base | 原奖励 R_base | 当前方法的同流程对照 | 从零，seed 1/2/3 |
| instant | R_base − 2q_0 | 额外惩罚的强度/形式对照，无预测 | 从零，seed 1/2/3 |
| predictive | R_base − 2q_4 | 唯一增强：4 s 匀速风险预测 | 从零，seed 1/2/3 |
| DWA | 既有验证选定控制器 | 真正避障基线 | 不训练、不重新选参 |

三组 PPO 均使用 D 场景生成族、同一验证集、同一算法参数。每个运行请求 200,000 步，按现有 n_steps=2048 完成实际 200,704 步；9 次训练总计请求 1,800,000、实际 1,806,336 步。资源安排是后续运行步骤，本次不消耗这些训练预算。

base 也重新从零训练，保证三组采用同一实现与选模规则。旧 D best 保留作历史参考，不将旧运行当作新增随机重复。相同 seed 用于配对初始化/随机流，但策略导致回合长度不同，不能声称三组经历完全相同的训练场景序列。

主比较为 predictive−instant，辅助比较为 predictive−base、instant−base 和 predictive−DWA。若仅优于 base 而不优于 instant，不能将收益归因于预测；可能只是额外惩罚的作用。相同最大惩罚并不等于累计惩罚量相同，累计量也必须报告。

## 3. 风险项的精确定义

### 3.1 只用可观测状态及固定几何常量

以当前船体坐标建立二维相对位置 r_j，j 为两个静态障碍和一个动态障碍。由同一 16 维观测中的距离、sin/cos 解码；速度用该观测的固定尺度解码，不读取未来轨迹、见证路径、风险标签或隐藏场景信息。

- 静态障碍相对速度 u_j = (−v, 0)，v 为实际当前航速。
- 动态障碍相对速度直接取观测中的船体相对速度，乘固定尺度 4.8。
- 膨胀半径 a_j：两个静态实体各 5 m，动态实体 4 m，即固定障碍半径加 USV 半径。

这里新项用表面净空表达几何风险，**不是把原中心距离观测和原安全奖励改成净空**。原奖励所有项保持不变，也不使用平方惩罚。固定半径是已有公开任务参数。

### 3.2 最近接近预测与线性映射

对于预测时域 H，定义：

```text
若 dot(u_j,u_j) <= 1e-12：tau_j = 0
否则：tau_j = clip(-dot(r_j,u_j) / dot(u_j,u_j), 0, H)
d_j(H) = norm(r_j + tau_j*u_j) - a_j
q_H = max_j clip((2.0 - d_j(H)) / 2.0, 0, 1)
```

参数固定：H=4.0 s，净空缓冲 2.0 m，新增权重 λ=2.0。instant 使用完全相同公式但 H=0；base 的新增权重为 0。对所有实体取最大风险而不求和，新增惩罚范围恒为 [−2,0]，避免实体数量叠加混入本轮因素。

时域 4 s 是覆盖当前最大航速约 2 s 制动时间并留提前量的工程初值，缓冲 2 m 和权重 2 是本协议的预先选择，不是搜索得到的最优值。**本轮不做参数网格搜索，也不因验证结果不理想追加挑选参数。** 若确需研究参数，另开明确版本，不能替换本轮结果。

预测假定当前实际速度和朝向保持不变，目标匀速；忽略未来转向和加速度。这是维持当前运动的风险代理，不是执行计划或保证真实碰撞发生的模型。已远离目标的最近时间被截为 0，零相对速度不能除零；远距离观测截断继续与 PPO 一致。

### 3.3 时序、终端与日志

一步执行后，在 s_(t+1) 的观测上计算新增风险项，与原 R_base(s_t,a_t,s_(t+1)) 相加。发生任意 terminated 或 truncated 时，新增惩罚置 0，保持原终端奖励不被额外项改写。训练与验证使用一致时序。

日志必须同时保存 base reward、risk penalty、training reward、q_0、q_4 及各实体净空/TCPA。跨组不直接比较不同定义的训练回报；共同评价奖励统一使用 R_base。训练曲线仍只画随机训练回合奖励和滚动均值，不添加标准差阴影，也不凭曲线平滑宣称收敛。

## 4. 固定训练与选模规则

- 环境：原 D 生成器、固定半径、匀速目标、dt=0.2、最大 600 步、原动作和加速度限制。无多障碍扩展、噪声、COLREGs、额外碰撞终止或速度硬上限干预。
- PPO：学习率 1e-4，n_steps=2048，batch=64，epochs=10，gamma=0.99，GAE=0.95，clip=0.2，entropy=0.01；pi/vf 均 64×64 Tanh，其他默认参数在实现封存时完整记录，所有组一致。
- 固定 seed：1、2、3；CPU；新 run-id 为 round3-{base,instant,predictive}-seed{1,2,3}。不从 best/final 续训，不删除差 seed，不增加预算直至好看。
- 共同验证集：`configs/round1/validation_D.json`，60 个场景。开发诊断使用 common_encounters、typical_cases，数据用途不升级为最终测试。
- 每 10,000 步及最后一次参数更新后评估，依次按成功率高、碰撞率低、成功路径效率高、**共同 base reward 高**选 best；完全相同时保留较早候选。无成功时效率按 0。不能使用各组不同的 shaped reward 作为最终决胜项。
- 旧 D 模型选模流程没有这一新增分项需求，因此主实验不直接复用旧 best。base 组应验证与原环境数值等价，但新运行仍保留独立身份。
- DWA 沿用第二轮 validation_tuning/selection.json 中 h3-c1，运行前验证配置和源码哈希。不得因它表现强而减采样、改净空或改终止规则。

## 6. 指标、统计与判读

主指标：常规测试成功率的 predictive−instant 配对差。每组报告 3 个 seed 单独结果、均值、样本 SD 和 seed t 区间；差值采用 seed 配对、会遇类型内场景配对的层级 bootstrap，10,000 次，统计 seed 5821，给出双侧 95% 区间。挑战和其他比较为辅助探索性结果，不声称多重比较校正后的显著性。

若主差值为正且区间下界大于 0，可称本受控协议下有支持预测收益的证据；否则只报告估计差与不确定性，不能以某个 seed 或某个类型提升替代主结果。三个 seed 的推断仍有限，即使区间不含零也不代表普适因果结论。

必须同时报告：静态/动态碰撞、越界、超时、最小净空、成功条件下的路径效率/到达时间，以及全回合结果。安全性和效率相互制约，停车超时不能当作避障成功。DWA 对照无论高低都完整保留。

机制指标（各组均用同一诊断定义，不用于选模）：

- 确定性速度均值裁剪比例、初始 2 s 后满速比例。
- q_4≥0.5 的高预测风险状态下航速、减速度及角速度分布。
- 每回合首次 q_4≥0.5 且 t≥2 s 后，到首次单步降速≥0.1 m/s 的延迟；未响应作为删失/无响应单列，不能剔除。该指标只是行为代理，不能代替成功率。
- 原安全项与新增项的累计值、触发步数、终端和 base return；检查预测组收益是否伴随更多累计惩罚。
- 成功与失败分别报告，不因幸存者筛选掩盖风险；保存全部逐步轨迹，失败图按 ID 顺序取样。

可能的负结果包括：仍持续满速、为了避免风险原地停留、对已可安全转向的直线预测过度惩罚、把损失转移为超时、instant 与 predictive 相当。均保留，不把失败自动解释为“训练不够”。
